# 파이썬 기초 퀴즈 게임

## 프로젝트 개요
터미널(콘솔)에서 동작하는 Python 퀴즈 게임입니다.
- `Quiz`, `QuizGame` 두 클래스로 역할을 나누어 구현했습니다.
- 추가한 퀴즈와 최고 점수는 `state.json`에 저장되어 프로그램을 다시 실행해도 유지됩니다.
- Git으로 기능 단위 커밋, 브랜치 작업/병합, clone/pull을 수행하며 이력을 관리했습니다.

## 퀴즈 주제 선정 이유
퀴즈를 만들면서 Python 기초 문법(자료형, 조건문, 반복문, 함수)을 복습할 수 있고, 정답이 명확해 검증이 쉬워 **파이썬 기초**를 주제로 선택했습니다.

## 실행 방법
- 요구 사항: Python 3.10 이상 (외부 라이브러리 없음)
```
python main.py
```

## 기능 목록
| 메뉴 | 기능 |
|---|---|
| 1. 퀴즈 풀기 | 저장된 퀴즈를 순서대로 출제, 정답/오답 안내, 결과와 점수 표시, 최고 점수 갱신 |
| 2. 퀴즈 추가 | 문제, 선택지 4개, 정답 번호(1~4)를 입력해 등록하고 즉시 저장 |
| 3. 퀴즈 목록 | 등록된 퀴즈의 문제 목록과 총 개수 표시 |
| 4. 점수 확인 | 최고 점수 표시 (아직 안 풀었으면 안내) |
| 5. 종료 | 종료 (저장 후 종료) |

공통 입력 처리: 앞뒤 공백 제거, 숫자 아님/범위 밖/빈 입력 시 안내 후 재입력, Ctrl+C·입력 종료(EOF) 시 저장 후 안전 종료.

## 데이터 파일 설명 (`state.json`)
- **경로:** 프로젝트 루트 (`main.py`와 같은 폴더), UTF-8 인코딩
- **역할:** 퀴즈 목록과 최고 점수를 저장해 재실행 후에도 유지
- **없을 때:** 기본 퀴즈 6개를 사용하고 첫 저장 시 생성
- **손상되었을 때:** 안내 메시지를 출력하고 기본 퀴즈로 초기화

```json
{
    "quizzes": [
        {
            "question": "파이썬에서 리스트를 만들 때 사용하는 기호는?",
            "choices": ["()", "[]", "{}", "<>"],
            "answer": 2
        }
    ],
    "best_score": 100,
    "best_total": 6,
    "best_correct": 6
}
```
| 키 | 의미 |
|---|---|
| `quizzes` | 퀴즈 목록 (`question` 문제, `choices` 선택지 4개, `answer` 정답 번호 1~4) |
| `best_score` | 최고 점수 (0~100, 아직 안 풀었으면 `null`) |
| `best_total` | 최고 점수를 냈을 때의 전체 문제 수 |
| `best_correct` | 최고 점수를 냈을 때의 정답 수 |
